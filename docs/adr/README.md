## Regras de manutenção

- Novas decisões arquiteturais devem ser registradas em ADR próprio.
- ADR aprovado não deve ser reescrito para ocultar histórico; mudanças relevantes devem criar nova decisão ou registrar revisão explícita conforme processo do projeto.
- SPECs futuras devem respeitar os impactos declarados nos ADRs aplicáveis.
